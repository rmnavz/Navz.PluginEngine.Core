# Contributing to Navz.PluginEngine.Core

Thank you for your interest in contributing! We welcome all types of contributions, including bug reports, feature requests, documentation improvements, and code changes.

## How to Contribute

1. **Fork the repository** and create your branch from `develop`.
2. **Write clear, descriptive commit messages**.
3. **Add tests** for new features or bug fixes.
4. **Update documentation** as needed.
5. **Open a pull request** with a clear description of your changes.

## Code Style

- Follow the existing code style and formatting.
- Use XML documentation for all public APIs.
- Keep dependencies minimal.

## Branching Strategy

- `main`: Stable, production-ready code
- `develop`: Latest development changes
- `feature/*`: New features
- `bugfix/*`: Bug fixes
- `release/*`: Release preparation
- `hotfix/*`: Critical fixes

## Reporting Issues

- Use [GitHub Issues](https://github.com/rmnavz/Navz.PluginEngine.Core/issues) for bugs and feature requests.
- Provide as much detail as possible, including steps to reproduce and environment info.

## Community

- Join [GitHub Discussions](https://github.com/rmnavz/Navz.PluginEngine.Core/discussions) for questions and ideas.
- Be respectful and constructive in all communications.
